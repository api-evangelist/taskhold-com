Taskhold provides a hosted task list that developers and their AI coding agents share, enabling agents to report progress and ask questions through the Model Context Protocol (MCP) while users answer via a live board. It integrates with Claude Code, Cursor, Codex, Windsurf, VS Code, Gemini CLI, claude.ai and ChatGPT, and is priced per person at $12 per month or $120 per year after a 7‑day trial.

**Areas:** AI coding agents · Model Context Protocol · Developer tools

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for taskhold-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
